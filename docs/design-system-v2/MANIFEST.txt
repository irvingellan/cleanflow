DESIGN_SYSTEM_V2.md                          PROPOSED DIRECTION
  Philosophy, colour roles with measured contrast, state system, typography,
  spacing, radii, sizes, page templates and breakpoints, application shell,
  perceived-performance rules, localization findings, accessibility rules.

COMPONENT_CATALOG.md                         PROPOSED DIRECTION
  Every component: purpose, anatomy, variants, states, responsive behaviour,
  accessibility notes, and the current class or component it replaces.

TOKENS.json                                  PROPOSED DIRECTION
  Implementation-neutral semantic tokens: colour roles for light and dark,
  state definitions, typography, spacing, radii, sizes, layout, breakpoints,
  elevation, motion; a map from the current CSS variables to V2 roles; the list
  of values that differ from today's stylesheet.

MIGRATION_PLAN.md                            PROPOSED DIRECTION
  Ten incremental phases (A Tokens ... J Legacy cleanup), dependencies, what
  can run in parallel, what must not be bundled, rollback.

CODEX_HANDOFF.md                             PROPOSED DIRECTION
  Eight engineering goals. For each: source artboards, components required,
  behaviour that must remain, visual / responsive / theme / localization
  acceptance, what must not change, and which drawn items are OPTIONAL.

VISUAL_ACCEPTANCE_CHECKLIST.md               PROPOSED DIRECTION
  Reusable checklist to run after every UI implementation, with the screenshot
  set to attach.

UX_AUDIT.md                                  SUPPORTING REFERENCE
  Audit of the current product (shell, navigation, headers, cards, lists,
  filters, forms, buttons, badges, icons, disclosures, alerts, confirmations,
  loading / empty / error, tokens, localization), each marked KEEP, IMPROVE,
  REPLACE or CONSOLIDATE, with counts taken from the stylesheet. Created during
  the mission in addition to the documents the brief listed.

SCREEN_INVENTORY.md                          SUPPORTING REFERENCE
  Every current screen classified as Already aligned, Minor migration, Major
  migration or Internal/dev only, with the artboards that cover it.

MANIFEST.txt                                 SUPPORTING REFERENCE
  This file.

KNOWN LIMITS OF THIS PACKAGE
----------------------------
- Nothing here has been approved; see STATUS LABELS.
- The PNGs were rendered locally from the source files. The canvas itself was
  not opened to check that it renders the same.
- Portuguese wording was written by the designer and has not been reviewed by
  a native-speaking operator. Spanish was not drawn.
- Not drawn: Cleaners and Clients lists (row patterns are on 03), Payments,
  forms, detail screens other than Job detail, cleaner-facing and public pages.
  They are classified in SCREEN_INVENTORY.md.
- Not every artboard has a dark and a Portuguese export. On the canvas every
  screen can be switched between light and dark.
